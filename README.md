# who-up 🌍

An interactive 3D globe showing estimated awake humans worldwide, in real-time and with time-travel.

## Features (Building)
- 🌐 Live 3D interactive globe (WebGL)
- 👥 Estimated awake humans by location
- ⏱️ Time travel: rewind/fast-forward to any moment
- 🌙 Realistic day/night lighting
- 🎯 Responsive, playable, fun
