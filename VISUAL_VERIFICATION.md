# 👁️ Visual Verification Checklist — Maximum Impact

**10 minutes before judges arrive, verify these visual moments are STUNNING.**

---

## THE 5 CRITICAL VISUAL MOMENTS

### 1️⃣ **Counter Glow** (First thing they see)

**What to check**:
- [ ] Counter at ~5.2B (or current number)
- [ ] Glow is VIVID (orange/red halos, not faint)
- [ ] Glow extends 150+ pixels (not tight)
- [ ] Pulsing animation visible (counter breathing)
- [ ] Text is crisp, not blurry

**How judges judge this**:
*"Oh wow, that looks expensive"* (good) vs *"That's a number"* (bad)

**If glow is faint**: Browser zoom might be at 90%. Reset to 100%.

---

### 2️⃣ **Wake Wave Visibility** (The signature feature)

**What to check**:
- [ ] Cyan band visible at Earth's edge
- [ ] Band is pulsing (not static)
- [ ] Glow around the band (bloom effects)
- [ ] Visible at current rotation angle (not hidden on back side)

**How judges judge this**:
*"What's that cyan band?"* = YOU WIN

**If barely visible**: This might be OLED vs LCD screen difference (normal). It will become obvious in time-lapse.

---

### 3️⃣ **Stars Bloom** (Background polish)

**What to check**:
- [ ] Stars visible in background
- [ ] Stars are twinkling/shimmering
- [ ] Stars have glow halos (bloom effect)
- [ ] Not distracting, complements the scene

**How judges judge this**:
*"The background is beautiful"* = Polish detected

---

### 4️⃣ **Earth Texture Quality** (NASA Blue Marble)

**What to check**:
- [ ] Continents are recognizable (not random noise)
- [ ] Day side shows realistic colors (greens, browns, whites)
- [ ] Night side shows city lights (faint glimmers)
- [ ] Lighting transitions smoothly at terminator

**How judges judge this**:
*"This is actually Earth"* = Credibility gained

**If Earth looks procedural**: Asset didn't load. Refresh page.

---

### 5️⃣ **Live Badge Pulse** (Credibility indicator)

**What to check**:
- [ ] "● LIVE" badge visible, top-right corner
- [ ] Badge is cyan, pulsing
- [ ] Sync timestamp visible ("Synced X seconds ago")
- [ ] Timestamp updates every ~10 seconds

**How judges judge this**:
*"This is actually live"* = Trust established

---

## THE TIME-LAPSE MOMENT (The payoff)

When you click play at 1000x:

**Visual verification**:
- [ ] Cyan band VISIBLY sweeps around globe
- [ ] Counter changes rapidly (every 1-2 seconds visible)
- [ ] Insight text changes (different regions' activity)
- [ ] UTC time advances rapidly
- [ ] Animation is smooth, not jerky

**Judge reaction**:
*"I can see the global pattern"* or *"That's mesmerizing"* = MIND-BLOWING achieved

**If sweep is subtle**: This is a GPU/bloom rendering difference. It's still working, just less dramatic on some screens.

---

## THE PARTICLE MOMENT (Interaction proof)

When you click a region:

**Visual verification**:
- [ ] 8 cyan particles appear at click point
- [ ] Particles radiate outward
- [ ] Particles fade out over ~0.6 seconds
- [ ] Glow around each particle visible

**Judge reaction**:
*"This feels premium"* = Interaction quality proven

---

## PERFORMANCE VERIFICATION

**During demo**:
- [ ] No frame drops (animation stays smooth)
- [ ] No stutters when clicking
- [ ] Time-lapse doesn't lag
- [ ] Panel slide-in is smooth

**Console check** (F12):
- [ ] Zero red errors
- [ ] Zero orange warnings (non-critical)
- [ ] FPS indicator (if browser supports it) shows 50+ FPS

| **Engineer** | Performance, no jank, smooth framerate | Rapid clicking, time-lapse at 1000x |

## PRE-DEMO VERIFICATION PROTOCOL

1. **Load the page** (should take <3 seconds)
2. **Look at counter** — Is the glow vivid? Is it pulsing?
3. **Look at wake wave** — Visible? Pulsing?
4. **Click a region** — Do particles appear? Does panel slide?
5. **Click time-lapse** — Does control bar appear?
6. **Click play at 1000x** — Does band sweep? Is it smooth?
7. **Check console** (F12) — Any red errors?

**Time**: 90 seconds total

**Result**: Confirmation that all critical moments will work

---

## IF SOMETHING LOOKS OFF

| Issue | Likely Cause | Fix |
|---|---|---|
| Counter glow is faint | Browser zoom at 90% | Reset zoom to 100% (Ctrl+0) |
| Wake wave barely visible | OLED vs LCD screen | Normal. Will be obvious in time-lapse. OK to proceed. |
| Earth looks procedural | Asset failed to load | Refresh page (Ctrl+Shift+R hard refresh) |
| Particles don't appear | Cache issue | Hard refresh |
| Time-lapse is slow | Network lag | Try again. If persists, use regional click demo instead. |
| Console shows red errors | Shader issue (rare) | Hard refresh. If persists, use Vercel backup URL. |
